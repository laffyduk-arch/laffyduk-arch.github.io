# The studio

An early version of a writing studio that runs on your phone. Open
https://laffyduk-arch.github.io in your phone's browser, then choose
"Install app" or "Add to home screen".

Everything you write stays on your phone: nothing is sent anywhere. This
repository holds only the app's built files, published by GitHub Pages; it
holds no stories and no keys. The studio's source and documents live in a
separate, private repository.
